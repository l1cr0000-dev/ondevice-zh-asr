# 結束判定 scoreboard

共同設定：X-ASR 480 ms INT8、Silero VAD v6.2.3（threshold 0.5、min_speech 250 ms、pad 30 ms）、pre-roll 100 ms、10 ms chunk 模擬即時、單執行緒、Apple M5 / macOS 27.0.1。每條音訊前補 1 s、後補 1.5 s 數位靜音。
