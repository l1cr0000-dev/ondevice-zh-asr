## B9 短停頓：0.2 s 句間停頓的暫定結果（2026-11-01）

方案 A2 下 0.2 s 的句間停頓仍要 1.3 s（P90 3.7 s）才看到完整結果：VAD 的靜音以 32 ms frame 計，pause 200 實際要 7 個 frame（224 ms），而 0.2 s 停頓有 39% 的 VAD 靜音不滿 224 ms，停頓事件不發出，兩句合併。過程見 progress.md。

`d016396`+，onnxruntime 後端（`x-asr-480ms-int8-ort`），min_silence 1000、`--provisional finalize`，jobs 1。**同機有其他工作階段在跑評測（load average 4–5），RTF 與延遲的絕對值比上面各表高（A2 對照 RTF 0.061–0.105 vs 先前 0.033 / 0.071），只能看同批的相對差**；辨識結果、暫定結果、切段與負載無關（兩批重跑逐句相同）。計算量另以「解碼音訊 / 音訊」比較（原 stream 解碼 1 次 + 每次恢復說話從句段開頭重新解碼到停頓處；與負載無關）。
