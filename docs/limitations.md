# 泛化局限：所有優化都只在 AISHELL-1 小集合上驗證

2026-11-03 記錄。目前所有優化與預設參數，都是在 **AISHELL-1 test 的小集合**（200 句冒煙集、300 句 MFA 對齊集、其中 ≤ 3 s 的 100 句短句子集、由 300 句合成的連續多句集、混入 DEMAND TCAR 的車內噪音版）上量測與決定的。受算力限制，優化階段刻意不跑 3000 句；之後要在更大、更接近車艙的集合上重新驗證。

## AISHELL-1 與目標場景（智能車艙）的差距

| | AISHELL-1（評測集） | 智能車艙（目標） |
|---|---|---|
| 說話方式 | 照稿**朗讀**的新聞句（財經、科技、體育、娛樂） | **自然口語**指令，有猶豫停頓與語助詞（「嗯…打開那個空調」） |
| 長度 | 平均 4–5 s | 多在 1–3 s |
| 錄音 | 安靜環境、近講麥克風 | 車內遠場麥克風，經 SSE 語音增強，可能有處理殘留；有車門、方向燈、敲擊等瞬態聲 |
| 內容 | 一般新聞詞彙 | 車控指令、地名、人名、App 名稱，偶爾夾英文（「CarPlay」） |
| 說話人 | 3000 句只有 20 位 | 不特定駕駛與乘客、口音多樣 |

另外，SenseVoice 與 X-ASR 都沒有公開完整的訓練資料清單，**很可能用過 AISHELL**（[models.md](models.md)），AISHELL 上的 CER 可能偏樂觀，兩個模型的比較也不一定公平。

## 各項優化的泛化風險

### 低：與資料無關，換資料結論不變

這些改動都驗證過辨識結果逐句不變，只影響計算方式或量測方法。

- onnxruntime 1.31.1 直接推論（取代 sherpa-onnx 內附的 ORT 1.28，記憶體碎片）
- X-ASR greedy search 批次 joiner
- SenseVoice 2 執行緒、關 spinning（`session.intra_op.allow_spinning=0`）
- 量測方法：首字 / 結果延遲定義、partial 穩定度指標（`eval/stability.py`）、麥克風路徑 vs 模擬即時的差距（B0）

### 中：機制成立，數字會變

- **語言固定 zh**：短音訊上自動語言判斷出錯是普遍機制；風險是夾英文的指令，目前只用 4 個中英混合測試音訊驗證。
- **熱詞**：方法通用；召回率是在「事先知道會出現哪些詞」的樂觀條件下量的（熱詞從評測句子挑出）。
- **A2 結束判定**（停頓 150 ms 先出暫定結果）：架構通用；暫定結果被修正的比例取決於說話方式。
- **偽串流排程**（0.48 s 第一次、之後每 0.96 s、> 3 s 不更新）：「長句段計算量有上限」是通用的，但 3 s 上限是以 AISHELL 句長與車艙指令長度的假設定的。

### 高：參數是從朗讀語料調出來的，最需要重新驗證

- **定稿門檻 min_silence 700 ms**（2026-11-03 起預設）：依據是 AISHELL 短句的句中最長低機率段（P90 192 ms、最長 384 ms）。口語的猶豫停頓常超過 500 ms，真實車艙中可能把一句指令切成兩段。已知代價：4–5 s 的朗讀長句被切開 2 → 8%，冒煙集 CER 3.43 → 3.80%（+0.37 個百分點，顯著）。**若在口語上發現誤切，退回 800 或 1000 ms**（`--min-silence-ms`）。
- **VAD 觸發參數**（min_speech 250 ms，未改）與第一次 partial 的時機：朗讀語音的起音乾淨，遠場與口語起音較模糊；誤觸發只在無瞬態噪音的資料上量過（0 次），不能當作沒有風險。
- **模型選擇（SenseVoice vs X-ASR）**：CER 差距（200 句 3.43 vs 4.80%）可能受訓練資料重疊影響；換跨領域資料後排序可能改變。
- **噪音結論**：TCAR 車內噪音能量 98.7% 在 100 Hz 以下，寬頻 SNR 高估了噪音對語音頻帶的干擾，−5 dB 也沒有誤觸發，量不出 VAD 的難處。

## 之後要做的驗證（算力允許時）

1. **3000 句正式集**重跑目前的預設，更新 README 的正式指標表（目前表中沒有 SenseVoice）。
2. **自錄車艙指令集**（由使用者錄製，100–200 句自然口語指令，含猶豫停頓、夾英文的 App 名稱，最好在車上錄），MFA 對齊後重驗高風險項：min_silence、VAD 觸發、第一次 partial、模型選擇。
3. **公開的口語 / 車載語料**：例如 MagicData-RAMC（對話）、WenetSpeech 的口語測試子集；據了解有車內多通道資料集 AISHELL-5，授權與大小需先查證，下載前需使用者同意。
4. **含瞬態噪音且經 SSE 前端**的車艙錄音，量誤觸發。
